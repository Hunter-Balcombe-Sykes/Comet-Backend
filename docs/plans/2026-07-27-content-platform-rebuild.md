## §0.1 Constitution (invariants that bind every section)

- **C1** Every durable *content* value is a typed column in a typed table — no bag columns for content. Bounded operational envelopes (landed raw docs, routing evidence, run cost/detail jsonb) are permitted with validated shapes. `site.platform_connections.payload` is scheduled for dissolution (§18) — its contents migrate to facets, profile fields, and brand assets; the column drops at P8.
- **C2** No `is_manual`/`is_manually_set` flags anywhere. Manual-ness is provenance: a manual source row, or a typed override row. The row *is* the lock.
- **C3** No scalar *configuration* inheritance for platform behaviour in any medium (base→category→platform chains are dead; v5 shipped them dead). Layered **derivation with provenance** (design-kit overlay, preset bucket→slug refinement) is not config inheritance and is explicitly sanctioned — the difference is that every layer is inspectable and manual always wins.
- **C4** Ingest never writes curation: never sort order, never pins, never un-hides, never clears a user removal.
- **C5** Reconcile, never replace. Absence requires completeness evidence (Coverage), domination, 3 confirmations, and the delete-guard. A zero-item fetch is `unavailable`, never emptiness. (This deliberately overturns the rules-engine council's "no tombstone machinery" rule — its derive-from-runs alternative rode on an append-only observation ledger we reject for storage cost; its protections survive as this clause.)
- **C6** Every billed effect claims budget exactly once and is ledgered (charge-once across retries). **Seven** keepers survive: the Fetch exception taxonomy, `FetchBudget::ensureOpen()`, `ApifyBudget::tryClaim()` + `PlacesBudget::claim()`, `SafeUrlFetcher`'s SSRF guard, `GoogleBusinessPayload::stripThirdPartyPii`, `GoogleBusinessEnrichJob`'s refuse-to-re-bill policy (generalised into the EffectLedger), **and `AiSpendBudget`** (menu OCR/AI — crowd caught its omission).
- **C7** Identity is computed by a pure re-runnable resolver over per-source records + human decisions — never accumulated at ingest; no unique index on any identity key value.
- **C8** The user outranks the machine everywhere: identity decisions beat a GTIN; a manual override beats every rule; a manual kit column beats autopilot; removals never resurrect.
- **C9** One implementation per concept: ONE `CanonicalUrl` canonicaliser (consumed by the router's Iri step, the ingest parsers, and the identity KeyClass), ONE matching engine (§2), ONE library template (§16), ONE brand-asset pipeline (§12), ONE replay/diff tool (`routing:reproject`).
- **C10** Effort is not a decision factor.

## §4. Ingestion — connectors, effects, landing, streams

Adopts the fetcher-architecture ruling; the rules-engine scheduler is merged with the seams the crowd flagged now resolved explicitly:

- **Layers:** Connector (pure; `static manifest()` + `pull(Pull, Io): iterable<Message>`; zero I/O, zero base classes; shared static parsers) → Io (the only I/O) → Landing (content-addressed `ingest.record_versions`, `UNIQUE(stream,key,doc_hash) DO NOTHING` — unchanged content writes zero rows; `record_state`; volatility rules; schema observation; 7 drift detectors; **delete-guard with reset**; per-stream suppression 1h→7d backoff) → Projection (pure, versioned; `RecordView` instrumented reads; pins; `ingest:project --dry-run|--diff|--shadow|--rebuild`).
- **Streams own the ingestion vocabulary end to end** (no `run_lanes`/`lane_outcome` terms anywhere): coverage per stream, `guard_tripped_at` on `ingest.streams`. The platform-hold breaker trips at >30% abnormal runs/hour where abnormal = `Unavailable | Shape | guard-tripped`.
- **Manifest owns stream declarations** (crowd correction: NOT the Surface — the Surface names its `fetchCapability`; that capability's connector class ships the Manifest): source key, identifier kind, hosts, cost class, default interval, redactions, `streams: {name → StreamSpec{target, requires, volatile, orderField, authoritativeFields, profile}}`.
- **`SourceProfile` lives on StreamSpec** {Mirror, Sample, Catalogue, Feed, Calendar, Identity} and drives: cadence band, absence policy, stale-display default, pinnable/editable flags (wired to the FE via §16's kind schema). **Sample semantics (reviews) fully specified** (crowd): a Sample stream never deletes and never dominates — records never tombstone; the *display set* is "records present in the latest ok run"; the GBP worked example is corrected accordingly (no `Coverage::prefix` on reviews).
- **PII redaction is claim-state-scoped** (crowd caught a live regression): `Manifest::$redactions` entries carry `always` vs `when_unclaimed`; claimed accounts land full reviewer fields (today's behaviour preserved — the strip is unclaimed-only, `GoogleBusinessFetch.php:68-70`); post-claim re-enrich re-fetches what unclaimed-era raw lacks.
- **Scheduler (one mechanism, stated):** `ingest.sources` = the fetch unit (one row per connection × source). Gains `cost_units`, profile-derived `[min,max]` interval band, `change_rate` EWMA (0.7/0.3 over last 10 qualifying runs; a qualifying run = outcome Ok with non-unknown coverage; Sample streams count latest-run doc-hash changes), and the **DB claim** (`in_flight_since/in_flight_run_id`, `UPDATE … RETURNING`) which is THE run lock — `ShouldBeUnique` and `Cache::lock` are **not** used for fetch jobs (the resolver job, a different resource, keeps `ShouldBeUnique` per user). `Deferred(retryAfter)` **releases the claim** and sets `next_attempt_at` (no false stranded alarms across Apify collect cycles). Stranded detector at 2h + alarm; the dashboard's 5-minute pending UX contract is honoured by surfacing "queued/running/deferred" states rather than a fake terminal state. Dispatcher every 15 min (overlap mutex retuned), score = staleness × visibility(1.0/0.25) ÷ (cost × (1 + user units today)); per-platform dispatch caps + stagger kept; manual refresh = cost×5 at staleness 10. Source-level `health` (dead after 10 consecutive Unavailable/Shape) gates eligibility — restored per rules-engine.
- **Budget denial semantics (stated):** `BudgetGate` raises per-effect `EffectRefused(Budget)`; connectors catch per-effect (Fresha pattern). An uncaught refusal → stream `Degraded` with `error_class=budget`; a run whose every effect was refused → `BudgetSkipped`. **Neither breaker level ever counts budget classes.** Chronic `Degraded` is not breaker-fatal but **is** suppression-eligible: per-stream suppression counts stream-attributed effect failures including degraded-with-error-class — so a permanently broken optional enrichment backs off (1h→7d) without killing its healthy sibling streams.
- Raw bytes: private `ingest` R2 disk (never the public media disk), `ingest/{connection}/{run}/{seq}.zst`, 14d TTL / 90d for anomaly runs; redaction before landing; user deletion purges by connection prefix.
- Capacity workstream (crowd): a dedicated Horizon supervisor lane for ingest + a rebuild lane, sized at P3 (the current shared `supervisor-1` at maxProcesses 2 cannot host the 15-min dispatcher + 200/min rebuilds); container/infra cost lines in §19.
- Testing: Tier P/C/S + capture/harvest/fixture-coverage ≥0.85 + purity tests + nightly live contract tests (§22). Six pilots: vimeo, bandcamp, spotify-oembed, instagram (2 streams), fresha, google-business (5 streams). Gate: if any pilot needs an escape hatch, fix the contract before connector #7.
