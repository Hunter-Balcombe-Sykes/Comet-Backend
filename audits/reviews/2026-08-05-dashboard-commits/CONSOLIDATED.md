    - **Where:** `app/Http/Controllers/Api/Platforms/CustomLinksController.php:257`
    - **Affects:** Every custom link on the dashboard. The Smart-order switch sorts on `popularityRank`, which is unconditionally `null` — so "engagement order" still means "stored order", exactly the bug `ba7c252a` set out to fix.
    - **Effort:** S (~0.5–1h)
    - **What to do:**
        - Key the lookup by the card's URL, not `resource_id`. `$card` is already constructed in that closure: `'popularityRank' => $linkRanks[(string) $card->url()] ?? null`.
        - Seed a real `content_popularity_scores` row in the contract test and assert a non-null rank (see #TEST-5 — the current test asserts `null` and would pass either way).
    - **Technical:** `ContentFreshness::boostsForSite()` writes `link_item` scores keyed by `$conn->payload['url']`; its docblock (`app/Services/Analytics/ContentFreshness.php:26-27`) states "payload.url is byte-stable … and equals the item's content_key". `CustomLinksController::linksData()` reads `$linkRanks[(string) $row->resource_id]`, where `resource_id` is `'link-'.substr(sha1(strtolower($url)), 0, 16)` (`:101`). Both derive from the URL, so they look interchangeable, but they never match — and `?? null` swallows the miss with no error. The **shop half is correct**: `ShopBrand::toBrandArray()` (`:135`) keys by `handle`, matching what the scorer writes, and that lookup was pre-existing.
    - **Plain English:** The dashboard has a switch that's meant to order links by how much people actually tap them. The code fetches the popularity numbers correctly, then looks them up under the wrong name — like filing records by phone number and then searching by surname. Nothing errors; the list just quietly stays in whatever order it was already in. The equivalent feature for shop products was wired up correctly in the same commit.
    - **Evidence:**
        ```php
        // written (ContentFreshness.php:78-83)
        if ($conn->platform === 'custom') { $linkItems[$url] = $conn->created_at; }

        // read (CustomLinksController.php:257)
        'popularityRank' => $linkRanks[(string) $row->resource_id] ?? null,
        ```
