- [ ] **#SLOP-5** · P3 — Identical sort comparator copy-pasted twice in the same method
    - **Where:** app/Services/Cache/SiteCacheService.php:501, :531 (resolveImageVariantUrlsInSite)
    - **Affects:** Maintainers — a bug fix or tiebreak change in one copy will almost certainly miss the other, causing drift.
    - **Effort:** S (~0.5–1h)
    - **What to do:**
        - Extract the sort closure into a private method, e.g. `private static function sortByOrderThenId(array &$items): void`.
        - Replace both `usort($site[$key], function ($a, $b) { … })` call sites with a call to that method.
    - **Technical:** The identical 11-line closure appears twice in this method — once for `gallery`/`content_images` arrays and once for `gallery_videos`/`content_videos` arrays — sorting by `sort_order` with an `id` fallback for stable ordering. `buildCombinedBlocksPayload` in the same file has a third, near-identical variant (same `sort_order`-then-`id` shape, minus the `is_array` guards), reinforcing that this is an established pattern worth extracting once rather than a one-off. Duplicating this logic runs against the "three similar lines > a premature abstraction" rule in reverse: 11 identical lines copy-pasted is exactly the drift risk a single shared helper exists to prevent.
    - **Plain English:** The same sorting recipe is written out twice on the same page (and a close cousin appears a third time nearby). If someone changes the recipe in one spot but forgets the other, the two dishes come out different. Writing the recipe once and pointing every spot at it means a future fix only has to happen in one place.
    - **Evidence:**
        ```php
        // First occurrence (gallery / content_images loop):
                    usort($site[$key], function ($a, $b) {
                        $aSort = is_array($a) ? (int) ($a['sort_order'] ?? PHP_INT_MAX) : PHP_INT_MAX;
                        $bSort = is_array($b) ? (int) ($b['sort_order'] ?? PHP_INT_MAX) : PHP_INT_MAX;
                        if ($aSort !== $bSort) {
                            return $aSort <=> $bSort;
                        }
                        $aId = is_array($a) ? (string) ($a['id'] ?? '') : '';

                    });
        ```
