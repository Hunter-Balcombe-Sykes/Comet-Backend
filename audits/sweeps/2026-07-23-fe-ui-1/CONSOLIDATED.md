A contract-drift finding here would necessarily cite only one side of the boundary (frontend markup with no backend counterpart to compare against), which the adjudication brief explicitly disallows. Confirmed clean rather than assumed clean.

**XDEAD (dead code):** rather than accept DeepSeek's "cannot trace imports at scan tier" abstention, adjudication ran the actual cross-file grep the brief requires before allowing any absence claim — in this case an inverse check (presence, not absence) since the candidate findings would have been "this export is unused." No orphan module, no commented-out block, and no reference to a removed subsystem (commerce/Shopify/Square/booking/affiliates) turned up in this file set — those remnants, where they exist elsewhere in the tree, are the intentional-dormancy category this campaign explicitly excludes.
